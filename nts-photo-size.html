NTS Form Photo Size: Common Errors and Fixes

Updated February 2026. Confirm the exact size in the official NTS notice for your test.

Short answer

NTS forms generally accept a recent JPG photo under a small KB limit. The most common failure is uploading a phone photo that is far over the limit. The second most common is using a PNG or WebP file when the portal expects JPG.

The two errors that cause most failures

File size too large

A phone photo is 2–5 MB. The form accepts a small fraction of that. Use the resize to KB tool: enter the limit from the NTS form, select your photo, download the result, and upload that.

Wrong file format

If you downloaded an image from WhatsApp or took a screenshot, it may be WebP or PNG. Convert it first with the PNG to JPG tool, then resize it.

Quick fix checklist

  • File is JPG
  • File size is under the stated KB limit
  • Photo is recent, front-facing, plain background
  • You are uploading the compressed file, not the original

What if the form still rejects it?

Check the official notice for any pixel-size requirement and use the pixel resize tool to match it. If the form requires 413×531 or a similar size, the passport photo tool will produce it in one click.

Common mistakes

  • Re-uploading the same large file and expecting a different result.
  • Assuming NTS uses the same size for every test — it can differ.
  • Using a photo that is not recent or not front-facing.

If the file is JPG, under the limit, and shows a recent front-facing photo, the upload normally works. If not, the problem is usually the file itself, not the portal.
