PPSC Photo and Signature Size Guide 2026

Updated February 2026. Always confirm the exact size in the official PPSC notice for your post.

Short answer

The Punjab Public Service Commission application usually asks for a recent JPG photo under a small KB limit (commonly 20–50 KB) and a JPG signature under a similar limit. The portal rejects the upload if either file is too large, and it does not tell you which one failed — so it is worth fixing both before you submit.

Why applicants get stuck

Phone cameras produce photos of 2–5 MB. The PPSC portal accepts a fraction of that. When the upload fails, most people try again with the same file and get the same error. The fix is to compress the file once and upload the compressed version.

Photo requirements

  • Recent, front-facing, plain light background
  • JPG format (not PNG, not WebP)
  • File size under the KB limit stated in the form
  • Clear face, no cap, no heavy shadow

Signature requirements

  • Signed on white paper with a black or blue pen
  • Photographed in good light, no shadow
  • JPG format
  • File size under the stated limit

How to fix a rejected photo

  1. Check the exact KB limit in the PPSC form.
  2. Open the resize to KB tool.
  3. Enter the limit and select your photo.
  4. Download the result and upload it.

How to fix a rejected signature

Same process: photograph the signature on white paper, then run it through the resize tool with the limit from the form. If the signature is a PNG, convert it first with the PNG to JPG tool.

Common mistakes

  • Trying to upload the original camera photo.
  • Using a screenshot instead of the actual photo file.
  • Not checking whether the form wants a photo and a signature separately.
  • Assuming the same size works for every PPSC post — it can differ.

If both files are under the limit and in JPG format, the upload usually works. If it still fails, check the official notice for any pixel-size requirement and use the pixel resize tool.
